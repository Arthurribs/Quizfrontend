React

O front-end é a camada de uma aplicação voltada para o usuário final, ou seja, tudo o que é exibido diretamente na tela e com o qual há interação visual (como botões, menus e formulários). Frameworks e bibliotecas como o React (desenvolvido pelo Meta), Angular e Vue.js executam exatamente essa função no navegador do usuário. Em contrapartida, opções populares como Spring Boot, Quarkus e Micronaut rodam do lado do servidor (back-end), processando regras de negócio, gerenciações de banco de dados e comunicação de APIs.
