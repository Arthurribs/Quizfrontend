- Interpretada: JavaScript é uma linguagem interpretada diretamente pelo navegador do usuário;
- Compilada: JavaScript não é uma linguagem compilada pois não precisa que seu código passe por um compilador para ser interpretada;
- Bytecode: JavaScript não é compilada e por isso não utiliza "bytecode" como Java
- No Case-Sensitivy: JavaScript é uma linguagem Case-Sensitivy pois você pode criar variaveis com o mesmo nome as diferenciando pela "Caixa-Alta" Ex:. Conta =/= conta
